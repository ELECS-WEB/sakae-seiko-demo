## 製品概要

CT-300 は、中小規模の自動化設備向けに設計されたコンパクトなプログラマブルコントローラ（PLC）です。豊富な拡張ユニットにより、入出力点数やアナログ・通信機能を柔軟に構成できます。当社センサー・計測器との親和性が高く、ライン全体を一括制御するシステム構築を容易にします。

## 主な仕様

| 項目 | 仕様 |
| --- | --- |
| 基本入出力 | DI 16 点 / DO 16 点 |
| 拡張 | 最大 8 ユニット |
| プログラム容量 | 32 K ステップ |
| 演算速度 | 基本命令 0.05 µs |
| 通信 | Ethernet / RS-485 / CC-Link |
| 電源 | DC 24 V |
| 使用温度 | 0〜55 ℃ |

## 用途例

- 搬送・仕分けラインのシーケンス制御
- 温調・圧力などのプロセス制御
- 複数センサーの集約と上位 PC への連携
