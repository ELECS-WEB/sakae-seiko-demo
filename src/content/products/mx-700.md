## 製品概要

MX-700 は、設備の異常振動を現場で手軽に測定できるハンディ型振動計です。加速度・速度・変位の同時測定に加え、内蔵 FFT 解析により周波数成分を可視化。回転機械のベアリング診断やアンバランス検出など、予知保全の現場診断に威力を発揮します。片手で扱える軽量設計です。

## 主な仕様

| 項目 | 仕様 |
| --- | --- |
| 測定量 | 加速度 / 速度 / 変位 |
| 周波数範囲 | 10 Hz〜10 kHz |
| FFT | 3,200 ライン |
| センサー | 圧電式加速度ピックアップ（付属） |
| 表示 | 3.5 インチカラー液晶 |
| メモリ | 内蔵 8 GB |
| 質量 | 約 320 g |

## 用途例

- 回転機械のベアリング異常診断
- ポンプ・ファンのアンバランス検出
- 定期巡回点検での振動トレンド管理
