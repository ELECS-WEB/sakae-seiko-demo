## 製品概要

SS-100 は、非接触で対象物までの距離・変位をマイクロメートル単位で計測できる高精度レーザー変位センサーです。生産ラインにおける寸法検査、厚み測定、位置決めなど、幅広い用途に対応します。コンパクト筐体ながら高い応答速度を実現し、高速搬送ラインへの組み込みにも適しています。

## 主な仕様

| 項目 | 仕様 |
| --- | --- |
| 測定範囲 | 30〜130 mm |
| 分解能 | 0.5 µm |
| 応答速度 | 最速 100 µs |
| 光源 | 半導体レーザー（クラス2） |
| 出力 | アナログ（4-20 mA）／ RS-485 |
| 使用温度 | 0〜50 ℃ |
| 保護等級 | IP67 |

## 用途例

- 電子部品の実装高さ検査
- 金属板・フィルムの厚み測定
- ロボットアームの位置決めフィードバック
- 振動・たわみのモニタリング
