## 製品概要

SS-200 シリーズは、金属体の接近を非接触で検出する誘導形近接センサーです。堅牢な円筒形状で、工作機械や搬送装置の位置検出に長年ご利用いただいてきました。本製品は後継機 SS-210 への移行に伴い、2024 年をもって生産を終了しています。補修・保守についてはお問い合わせください。

## 主な仕様

| 項目 | 仕様 |
| --- | --- |
| 検出距離 | 2 / 4 / 8 mm（型式による） |
| 検出体 | 鉄・非鉄金属 |
| 応答周波数 | 500 Hz |
| 電源電圧 | DC 12〜24 V |
| 出力形式 | NPN / PNP オープンコレクタ |
| 保護等級 | IP67 |

## 用途例

- 工作機械のワーク有無検出
- コンベア上のパレット位置検出
- シリンダーのストローク端検出
