## 製品概要

CT-800 は、既設の設備やセンサーから収集したデータをクラウドへ橋渡しする IoT ゲートウェイユニットです。Modbus / CC-Link などの産業用プロトコルを MQTT に変換し、遠隔からの稼働監視やデータ蓄積を実現します。エッジ側での簡易演算・アラート判定にも対応し、スマートファクトリー化の第一歩を支援します。

## 主な仕様

| 項目 | 仕様 |
| --- | --- |
| 対応プロトコル | Modbus/TCP・RTU / CC-Link / OPC UA |
| クラウド連携 | MQTT / HTTPS |
| エッジ処理 | しきい値判定・移動平均・ロギング |
| ネットワーク | 有線 LAN ×2 / Wi-Fi / LTE（オプション） |
| ストレージ | microSD（最大 128 GB） |
| 電源 | DC 24 V |

## 用途例

- 既設設備の遠隔稼働監視
- センサーデータのクラウド蓄積・可視化
- 異常発生時のメール・アラート通知
