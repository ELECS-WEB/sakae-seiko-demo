## 製品概要

MX-500 は、温度・電圧・電流・ひずみなど複数の物理量を同時に収録できる多チャンネルデジタル計測器です。7 インチのタッチパネルを搭載し、現場での波形確認と設定変更が直感的に行えます。収録データは USB / LAN 経由で PC に転送でき、品質管理や試験工程の記録に活用いただけます。

## 主な仕様

| 項目 | 仕様 |
| --- | --- |
| 入力チャンネル | 最大 32 ch |
| サンプリング | 最速 10 kS/s |
| 入力種別 | 熱電対 / 測温抵抗体 / 電圧 / 電流 / ひずみゲージ |
| 表示 | 7 インチ静電容量タッチパネル |
| 記録媒体 | 内蔵 SSD 64 GB / USB / SD |
| 通信 | LAN（Modbus/TCP）/ USB |
| 電源 | AC 100〜240 V |

## 用途例

- 製品試験時の多点温度収録
- 電源・バッテリーの充放電特性評価
- 構造物のひずみ・応力計測
- 長時間の環境モニタリング
